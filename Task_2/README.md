Данный проект используется для расчета времени выполнения программы перемножения матрицы и вектора.
Все результаты приведены в папке Report

Для того чтобы собрать проект, необходимо в терминале, находясь в директории ../CMake/ ввести следующие команды:

$ mkdir build 
$ cd build 
$ cmake .. 

далее, если все собралось без ошибок, ввести следующее для запуска:

$ ./app.out (значние N матрицы) (значение M матрицы) (кол-во потоков THEARDS)

Чтобы удалить созданный исполняемый файл нужно написать:

$ make clean
