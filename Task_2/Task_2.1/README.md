Данный проект используется для расчета времени выполнения программы перемножения матрицы и вектора.
Все результаты приведены в папке Report

Для того чтобы задать аргументы при запуске програмы, необходимо в терминал ввести:

$ export ARGS="(значние N матрицы) (значение M матрицы) (кол-во потоков THEARDS)"

Для того чтобы собрать проект, необходимо в терминале, находясь в директории ../Make/ ввести следующие команды:

$ make

далее, если все собралось без ошибок, ввести следующее для запуска(незабываем указать заранее переменную ARGS):

$ make run

Чтобы удалить созданный исполняемый файл нужно написать:

$ make clean
