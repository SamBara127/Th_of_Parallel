Данный проект используется для расчета времени выполнения программы которая содержит реализацию решения СЛАУ с 
использованием OpenMP.

Весь отчет приведен в папке "Report"
Все исходные файлы программы приведены в папке "Make"

Сам исходный файл "Source.cpp" включает в себя код программы в которой есть возможность выбирать вариант компилляции кода: 
1) Вариант, где для каждого распараллеливаемого цикла создается
отдельная параллельная секция #pragma omp parallel for.
2) Вариант, где создается одна параллельная секция #pragma omp parallel, 
охватывающая весь итерационный алгоритм.

Также внутри исходного файла можно менять значение матрицы N (#define N 256 // Размер пластинки (NxN)) - тут стоит 256
и точность вычисления (#define EPSILON 0.00001 // Точность) - тут стоит 0.00001

В файле сборки "Makefile" можно настраивать колличество потоков вычисления в переменной "THREADS"

-----------СБОРКА-------------

Для того чтобы собрать проект, необходимо в терминале, находясь в директории ../Make/ ввести следующие команды:

$ make FIRST=1 - если мы собираем первый вариант решения
или
$ make SECOND=1 - если мы собираем второй вариант решения

далее, если все собралось без ошибок, ввести следующее для запуска:

$ make run

Чтобы удалить созданный исполняемый файл нужно написать:

$ make clean
