Данный проект используется для многопоточной обработки датчиков и вывода их на изображение.

Весь отчет приведен в папке "Report"
Все исходные файлы программы приведены в папке "Make"

Для того чтобы запустить проект, необходимо в терминале, находясь в директории проекта ввести следующие команды:

$ python3 -m venv "название виртуальной среды" - чтобы не засорять системное окружение

далее, если все создалось без ошибок, ввести следующее для активации среды:

$ source /"название среды"/bin/activate

Потом необходимо установить библеотеки через pip модуль:

pip install -r requirements.txt

После успешной установки  можно переходить в директорию Python и запускать проект main.py:

$ cd Python
$ python main.py -h

тут уже разозбаться нужно с агрументами и все
(можно и без них) 
выход из программы осущетсвляется на кнопку "q"
