Данный проект используется для расчета времени выполнения программы которая содержит реализацию решения СЛАУ с 
использованием OpenACC.

Весь отчет приведен в папке "Report"
Все исходные файлы программы приведены в папке "Make"

Сам исходный файл "Source.cpp" включает в себя код программы.

В файле сборки "Makefile" можно настраивать такие параметры-переменные как:
	
EXE - название исполняемого файла
CPP - Название исходного файла
FL - флаги подключаемых либов

RESOLUTION - длина боковой стороны сетки
ACCURACY - точность
ITERATION - количество максимальных итераций

-----------СБОРКА-------------

Для того чтобы собрать проект, необходимо в терминале, находясь в директории ../Make/ ввести следующие команды:

$ make gpu 

далее, если все собралось без ошибок, ввести следующее для запуска:

$ make run -h

выведется окно справочника параметоров, по нему и запускать исполняемый файл

Чтобы запустить профилирование файла нужно написать:

$ make profile

Чтобы удалить созданный исполняемый файл нужно написать:

$ make clean
